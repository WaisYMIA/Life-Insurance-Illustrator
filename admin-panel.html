App updates & control

Installed apps check this every time they are opened (when online) and again at least once every "check interval" while open. Only set "Latest released version" to a version you have already deployed, or agents will be asked to install an update that does not exist yet. Publishing new files is done by deploying them (run node scripts/bump-version.js <version> first); the settings below decide how phones react.

Agents below the minimum version are blocked until they update. This is enforced inside the app, so it stops ordinary use but cannot stop a technically determined person tampering with their own device.
